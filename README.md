# WI Keyword Translator (월드인포 키워드 번역)

월드인포(로어북) 엔트리의 트리거 키워드(초록불)를 다른 언어로 번역해서 **추가**해 주는 SillyTavern 확장이에요.
예: 한국어로 만든 무협 로어북을 중국어로 채팅할 때 `화산파` → `华山派` 키워드를 한 번에 넣기.

## 여는 방법 (3가지)
- 월드인포 편집창 두 번째 줄의 **언어 아이콘(文A)** 버튼 → 지금 열려 있는 로어북으로 바로 열림
- 마법봉(확장) 메뉴 → **월드인포 키워드 번역**
- 슬래시 커맨드: `/wi-translate 로어북이름`

## 사용 순서
1. 로어북 선택 → 범위(전체 엔트리 / 선택한 엔트리만) 선택
2. 추가할 언어 체크 (중국어 간체·번체, 영어, 일본어, 한국어)
3. 번역 방식 선택
   - **Google / Bing (무료, 토큰 0)**: 빠르지만 고유명사는 틀릴 수 있어요 (예: 화산파 → 火山波)
   - **AI 번역 (현재 연결된 모델)**: 무협 이름·문파명이 훨씬 정확해요. 세계관 힌트를 적을 수 있어요.
4. **스캔 & 번역** → 미리보기에서 틀린 건 직접 고치거나 체크 해제
5. **체크한 항목 적용** → 잘못 넣었으면 **마지막 적용 되돌리기** (이 확장이 넣은 키워드만 지워요)

## 건너뛰는 것
- 항상 켜짐(파란불) 엔트리, 정규식 키워드(`/.../`)
- 이미 그 언어로 된 키워드, 이미 있는 키워드(중복 추가 안 함)

## 보안 / 비용
- 엔트리 **본문은 어디로도 보내지 않아요.**
- 무료 번역: 키워드만 실리태번 서버를 거쳐 Google/Bing으로 전송
- AI 번역: 키워드 + 엔트리 제목만 현재 모델로 전송 (40개씩 묶어서, 엔트리 100개 기준 대략 수천 토큰)
- API 키 저장 없음, `eval`/`innerHTML` 사용 없음
