# WI Keyword Translator (월드인포 키워드 번역)

월드인포(로어북) 엔트리의 트리거 키워드(초록불)를 다른 언어로 번역해서 **추가**해 주는 SillyTavern 확장이에요.
예: 한국어로 만든 무협 로어북을 중국어로 채팅할 때 `화산파` → `华山派` 키워드를 한 번에 넣기.

## 여는 방법 (3가지)
- 월드인포 편집창 두 번째 줄의 **언어 아이콘(文A)** 버튼 → 지금 열려 있는 로어북으로 바로 열림
- 마법봉(확장) 메뉴 → **월드인포 키워드 번역**
- 슬래시 커맨드: `/wi-translate 로어북이름`

## 사용 순서
1. 로어북 선택 → 범위(전체 엔트리 / 선택한 엔트리만) 선택
2. 추가할 언어 체크 (중국어 간체·번체, 영어, 일본어, 한국어)
3. 번역 방식 선택
   - **Google / Bing (무료, 토큰 0)**: 빠르지만 고유명사는 틀릴 수 있어요 (예: 화산파 → 火山波)
   - **AI 번역**: 무협 이름·문파명이 훨씬 정확해요
4. (선택) 검증 켜기
   - **역번역 표시**: 번역 결과를 원래 언어로 되돌려 보여줘요 (무료 번역기 / AI 중 선택)
   - **교차 비교**: 구글 ↔ AI 결과가 다른 것만 ⚠️ 표시, `→ 华山派 사용` 버튼으로 바로 교체, `↩ 원래대로` 버튼으로 언제든 되돌리기
5. **스캔 & 번역** → 미리보기에서 틀린 건 직접 고치거나 체크 해제
6. **체크한 항목 적용** → 잘못 넣었으면 **마지막 작업 되돌리기** (이 확장이 넣은 키워드만 지워요)

## 창을 닫아도 괜찮아요
- **번역/AI 진단 중에 닫기**를 누르면 물어봐요: **백그라운드에서 계속** / **중지하고 닫기** / 취소
  - 백그라운드로 두면 창을 닫아도 계속 진행되고, 끝나면 알림이 떠요. 진행 중에 다시 열면 진행 상황이 보여요
  - 중지해도 그때까지 된 결과는 남아요
- **마지막 결과 자동 저장**: 로어북별로 마지막 번역·진단 결과를 저장해 두고, 다시 열면 `📌 마지막 결과를 불러왔어요`로 이어서 볼 수 있어요
  - 미리보기에서 고친 내용, 체크 해제, "→ … 사용"으로 바꾼 것까지 그대로 남아요
  - 그 사이에 이미 들어간 키워드나 지워진 엔트리는 자동으로 빠져요
  - 적용하면 해당 결과는 지워지고, **결과 지우기** 버튼으로 직접 지울 수도 있어요
  - 저장 위치: 실리태번 사용자 폴더의 `user/files/wikt-cache-….json` (로어북당 작은 파일 하나, 서버라서 다른 기기에서도 이어짐)

## 되돌리기
- 번역 적용, 진단 적용, 언어별 삭제 모두 **마지막 작업 되돌리기**로 한 단계씩 되돌릴 수 있어요 (최근 15개)
- 기록은 실리태번 설정(서버)에 저장돼서 **창을 닫거나 새로고침해도, 다른 기기에서 열어도** 남아 있어요

## 진단 탭 (버튼 눌렀을 때만, 채팅을 계속 감시하지 않아요)
**읽을 채팅 범위**: 최근 N개 / 메시지 번호 지정(#시작 ~ #끝) / 채팅 전체, 숨긴 메시지 포함 여부
**점검할 키워드**: 이 확장이 추가한 키워드만(추천) / 모든 키워드

### 빠른 진단 (토큰 0)
키워드 글자가 채팅에 나왔는지만 세요. 번역기를 열면 탭에 `진단 (3)`처럼 삭제 추천 개수가 떠요.
- **삭제 추천**: 같은 글자 종류(한자/한글/라틴/가나)의 다른 키워드는 걸렸는데 이것만 0회
- **보류**: 엔트리 자체가 아직 안 나옴

### AI 정밀 진단 (토큰 소모)
AI가 고른 범위의 채팅을 읽고 엔트리가 실제로 어떻게 불렸는지 찾아요.
- **학습(+ 추가)**: 채팅에서 무림맹을 `武林盟`으로 썼으면 → `武林盟`을 키워드로 추가 후보
- **잘못된 키워드(− 삭제)**: 엔트리는 언급됐는데, 같은 글자 종류의 키워드(`無林猛`)가 한 번도 안 걸림 → 삭제 후보
- AI가 지어낸 표기(채팅에 실제로 없는 글자)는 자동으로 버려요
- 보내기 전에 요청 수와 글자 수를 확인 창으로 보여줘요. 범위가 길면 설정 탭의 크기대로 나눠서 보내요

### 언어별 키워드 지우기 (다시 번역하기 전에)
고른 언어(+ 채팅에서 학습한 표기)의 키워드를 미리보기 후 한 번에 지워요.
- "이 확장이 추가한 키워드만": 넣을 때 기록한 언어로 정확히 골라요 (1.0.4 이후 넣은 것)
- "모든 키워드": 글자 종류로 추정 (간체/번체 구분 불가, 한자만 있는 일본어는 중국어로 잡힘)

공통: 키워드가 하나도 안 남게 되는 삭제는 막고, 모두 되돌리기 가능해요.
번역 결과에도 "채팅 N회" 등장 횟수가 표시돼요 (토큰 0).

## 설정 탭
번역기 창 위쪽의 **설정** 탭에서:
- **AI 연결**: 현재 연결 또는 저장된 연결 프로필
- **본문 앞부분 글자 수**, **번역 프롬프트 보기/수정**
- **속도 · 묶음**: 한 번에 보내는 개수, 요청 사이 대기 시간 (무료/AI 따로). "추천값으로 복원" 버튼 있음
  - 추천값: 무료 30개 · 0.5초 / AI 30개 · 1.5초 / AI 진단 채팅 8000자 · 엔트리 60개
  - 실패하면 3초 이상 쉬고 한 번만 재시도, 그래도 실패하면 멈춰요 (연타 X)

## AI에게 보낼 정보 (번역 탭)
| 선택 | AI가 보는 것 | 정확도 | 토큰 |
|---|---|---|---|
| **키워드만** | 엔트리 제목 + 같은 엔트리의 다른 키워드 | 소리만 같은 한자(청명 → 清明/晴明)를 헷갈릴 수 있음 | 가장 적음 |
| **본문 일부** | + 엔트리 내용 앞 N자 (기본 300) | 대부분 충분 | 몇 배 |
| **월드인포 전문** | + 엔트리 내용 전체 | 가장 정확 | 가장 많음 |

- AI가 확신하지 못하면 후보 2개와 함께 ⚠️ "AI가 확신 못함"으로 표시돼요
- Google/Bing은 키워드를 한 단어씩 따로 번역해서 이 선택이 적용되지 않아요
- 본문은 AI 연결로만 가고 구글/빙으로는 절대 안 가요

## AI 번역 설정
- **AI 연결**: 현재 연결(채팅에 쓰는 API) 또는 저장된 **연결 프로필**(Connection Profile) 중 선택. 채팅은 비싼 모델, 번역은 싼 모델로 나눠 쓸 수 있어요.
- **세계관 메모**: 예) "한국 무협 세계관. 인물·문파 이름은 한자 표기로."
- **보낼 정보**: 위 표 참고 (키워드만 / 본문 일부 / 월드인포 전문)
- **번역 프롬프트 보기/수정**: 기본 프롬프트가 들어 있고, 고친 뒤 **기본값 복원**으로 되돌릴 수 있어요.
  (대상 언어, 세계관 메모, JSON 응답 형식, 키워드 목록은 자동으로 붙어서 고쳐도 망가지지 않아요.)

## 건너뛰는 것
- 항상 켜짐(파란불) 엔트리, 정규식 키워드(`/.../`)
- 이미 그 언어로 된 키워드, 이미 있는 키워드(중복 추가 안 함)

## 보안 / 비용
- 무료 번역: 키워드만 실리태번 서버를 거쳐 Google/Bing으로 전송 (무료 웹 번역이라 학습 미사용 보장은 없어요 — 그래서 본문은 절대 안 보내요)
- AI 번역: 키워드 + 엔트리 제목 (+ 켰을 때만 본문 앞부분)을 고른 연결로 전송. 보내기 전에 양(글자 수)을 확인 창으로 보여줘요.
- API 키 저장 없음, `eval`/`innerHTML` 사용 없음
